# 语音链路计时

每句话记录关键时间，以 `TIMING ` 开头的单行 JSON 写到标准错误；通过 `start-dev.sh` 启动时，由现有 `tee` 保存到本次 `test-db/logs/ro-agent-dev-*.log`。启动装配只打开 `robot_agent.timing` 日志通道，不改变其他日志等级。修改后需要重启平台才能生效。

## 时间口径

- 接收时间是平台应用 `receive_text()` 读到 WebSocket 消息的时刻，不是声卡采集时间，也不是操作系统网络缓冲区收包时间。处理繁忙造成的缓冲仍可能发生在这个时间点之前。
- 每包时间仅在内存中按字节范围短暂保留。VAD 用 32 毫秒窗口判断有效语音；窗口可能跨包，第一段有效窗口取首字节所在包的时间，最后一段有效窗口取末字节所在包的时间。不会把连接开始时的静音当成每个任务的起点。
- `audio_duration_ms` 是音频长度，不是处理耗时。`speech_receive_span_ms` 是相关包的读取时间跨度；批量上传时可能接近零，不能当作说话时长。
- 切句完成指内存 WAV 已组装完成，早于可选的录音保存。`endpoint_delay_ms` 包括有效语音结束后等待静音、调度及切句处理，不单独代表 VAD 运算耗时。
- ASR 计时包围实际适配器调用，包含音频请求准备、连接、网络、供应商处理、接收和解析；不包含随后写入识别结果的时间，不等于供应商内部推理时间。
- 日志的绝对时间用带 UTC 时区的 ISO 时间；同一模块的毫秒耗时用单调时钟计算。日志与数据库时间相减还依赖两者系统时钟一致。

## 日志与关联

| event | 内容 |
| --- | --- |
| `pcm_segment` | 客户、机器人和 `segment_id`；`first_speech_received_at`、`last_speech_received_at`、`segment_completed_at`；接收跨度、等待切句耗时、首段有效语音到切句耗时、音频长度及结束原因 |
| `asr_started` | 客户、机器人、`request_key`、`input_id` 和 ASR 开始时间 |
| `asr_finished` | 相同标识、开始／结束时间、`elapsed_ms`、成功／失败／取消；失败只记录异常类型 |
| `asr_reused` | 重复请求使用原识别结果，不伪造一次耗时为零的新 ASR 调用 |
| `input_task_linked` | 输入与任务关联已写入后的时间，包含 `request_key`、`input_id`、`conversation_id`、`turn_id`；这不是任务创建时间 |

PCM 请求的 `request_key` 等于 `segment_id`；通过 `input_task_linked` 找到执行轮次 `turn_id`，再关联 `ra_tasks.task_id`、`ra_llm_calls.turn_id`、`ra_plans.task_id` 和 `ra_task_events.task_id`。整段 WAV 请求没有 PCM 收包／切句记录，但使用同一套 ASR 计时。

已有数据库时间继续用于任务创建、规划开始、模型调用、计划保存和 `planned` 事件。`ra_llm_calls.finished_at-started_at` 包含客户端请求及结果解析、审计事务等时间，不能称为纯模型推理时间；`planned` 也可能对应澄清、普通回复或失败，必须结合事件中的状态判断是否真的产生了计划。

日志不记录音频、识别文本、提示词或密钥。未增加数据库表，不逐包写日志。

## 2026-11-12 已有测试数据

来源：本机 64 平台测试库 `ro_agent_sim_test`（55440）的只读查询及已有 `pcm-upload-report.json`。共 40 个任务轮次、5 次语音输入、33 次模型调用。这是跨日期的历史测试样本，不代表新日志已经验收或正式环境的性能。

| 指标 | 样本数 | 结果 |
| --- | ---: | --- |
| 独立 ASR 适配器计时 | 3 | 平均 2.794 秒，范围 2.661～2.921 秒 |
| 语音输入记录创建至任务创建，包含转写和受理 | 5 | 平均 2.876 秒，范围 2.667～3.237 秒 |
| 成功模型调用，relay / gpt-6.1-sol | 31 | 平均 6.480 秒，中位数 5.434 秒，范围 3.355～14.360 秒 |
| 第一轮确实生成待批准计划：任务创建至 planned | 13 | 平均 6.939 秒，其中模型调用前 0.135 秒、调用 6.780 秒、调用结束后 0.024 秒 |
